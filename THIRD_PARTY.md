# Outils utilisés

- [Remotion](https://www.remotion.dev) 4.0.534 (`remotion`, `@remotion/cli`, `@remotion/google-fonts`), installé par npm : licence Remotion, gratuite pour les particuliers et les petites entreprises (remotion.dev/license).
- Polices Archivo Black et Caveat Brush (Google Fonts, licence SIL Open Font) : chargées par `@remotion/google-fonts`.
- React 19, TypeScript : licences MIT / Apache-2.0.
- Apple Vision (`VNDetectHumanBodyPoseRequest`) : fourni avec macOS, appelé par `montage/scripts/pose.swift`.
- Bruitages : fabriqués par calcul (`npm run sons`), aucun son de tiers.
- L'hologramme n'est pas fait par ce kit : la personne utilise l'outil de transfert de mouvement de son choix (le créateur du kit a utilisé Higgsfield Genjutsu Lite), sur son propre compte.
